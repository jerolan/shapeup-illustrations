# Development material

`iterations/2026-10-29/` preserves the earlier generated examples and their original
prompt records. These are exploration history, not default generation references.
Records retain historical paths as originally used. The active, approved examples
live in `examples/`; original drawing provenance lives in `references/sources.md`.

Fresh-session checks go in `reviews/`, with a brief, the exact image-generation
prompt, final PNG, and observations for each case. Keep human approval distinct
from mechanical verification. Do not load this directory for ordinary generation.
