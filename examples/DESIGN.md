# Example palette

This palette applies to the generated examples in this directory. It is not a default for projects that install the skill.

- Background: white, `#FFFFFF`.
- Ink and text: near-black, `#171717`.
- Optional accent: violet, `#7C3AED`, for a selected option, meaningful revision, or critical dependency. Use only when emphasis helps; monochrome output is valid.
- Drawing: sparse hand-drawn outlines, unfilled people, and readable handwritten text.

An explicit accent in a request overrides the violet accent without changing the background or ink.
