## Select by explanatory need


Start with one row, inspect one or two images, and attach the selected drawings to
the generator when supported. Read the full sequence only when continuity is the
question. The index below retains provenance for all 23 originals; it is not a
request to load the gallery.

| Need | First references to inspect | What to borrow |
| --- | --- | --- |
| People and conversation | 01-team-tension; 02-shared-discovery | Proportions, gestures, bubbles and sparse pen work |
| Compact list or rough structure | 06-marker-sketch; 16-list-sequence | Marker weight and visible list edits |
| Scope or partition | 08-scope-map; 13-map-sequence | Boundaries, stable outline and emerging structure |
| Construct or revise a relationship | 14-flow-sequence; 05-interaction-flow | Persistent artifact and explicit changed connections |
| Integration or decisive dependency | 15-integration-sequence; 07-integrated-slice | An unchanged conclusion until a meaningful relation exists |
| Uncertainty or movement | 12-hill-sequence | Stable path and identifiable moving point |
| Hidden size or effort | 09-hidden-effort | Schematic volume and visible/hidden relationship |

Generated examples in `examples/` can guide composition but do not replace original
style calibration. An earlier generated frame is useful for continuity, not evidence
for facts or a license to repeat the same metaphor for every request.
